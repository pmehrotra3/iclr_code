Stage 2 in a nutshelllines 1–34

The experiment itself. For every (d, K, repeat seed) cell and every anchor budget b:

  1. Plant anchors around the modes in data space (core.ball_anchors).
  2. Backtrack them to seed space with the exact field.
  3. Fit each predictor on the (seed, fate) pairs (fate.py).
  4. Ground truth: fates of 50 000·K fresh seeds under the learned sampler (cached by train.py).
  5. Score each predictor against it.

Results are saved per cell, so an interrupted or partial evaluation resumes where it stopped, and a new budget or predictor only computes its own rows.

 1"""evaluate.py — Stage 2: build the seed-fate atlas and score it (same for ddim and flow).
 2
 3For every (d, K, seed) cell and every anchor budget b we
 4  1. plant labelled anchors around the modes in data space: b points per mode inside its R99
 5     ball plus a thin band just outside it, which counts as hallucination (core.ball_anchors);
 6     altered_knn gets its own weighted rings instead,
 7  2. carry them back to seed space with the exact field (proc.true_field_backtrack),
 8  3. fit each predictor in classifier.models on those (seed, fate) pairs (fate.py),
 9  4. take the ground truth: the fates of eval.n_eval_per_mode * K fresh seeds under the learned
10     sampler (train.py caches these), and
11  5. score each predictor against that ground truth (fate.fate_metrics).
12
13Results go to output/<run_id>/<process>/<variant>/T<T_true>/. Each cell's rows are kept in
14cells/d<d>_K<K>_s<seed>.json, and a row that is already there is not recomputed (unless
15eval.force=true), so adding a budget or a predictor only computes the new rows. Every row uses
16fixed seeds, so a cell built up in pieces is identical to one computed in one go.
17results.json (per-seed rows plus the mean / std over seeds) and the two csv files are then
18rebuilt from all cell files.

preflight(): fail in seconds, not hourslines 63–76

Estimates the GPU memory the biggest budget will need (all anchors, the ring anchors, the evaluation seeds, at 4 bytes per number, plus ~3 GB working space) and stops immediately if it is above 92% of the free memory, with advice on what to shrink. Without this, a d = 512 job could run for hours and then die of an out-of-memory error.

63def preflight(cfg, d, K, device):
64    """Stop early (not with a CUDA OOM hours in) when the largest budget cannot fit the GPU.
65    Peak ~ ball+shell anchors + altered_knn rings + eval seeds (fp32) + ~3 GB working memory."""
66    if device.type != "cuda":
67        return
68    b, f = max(budgets(cfg)), 4 * d
69    n_alt = b * K if any(s["arch"] == "altered_knn" for s in _specs(cfg)) else 0
70    need = (b * K * (1 + float(cfg.anchors.shell_frac)) * f + n_alt * f + n_eval_for(cfg, K) * f + 3e9) / 1e9
71    free, total = (x / 1e9 for x in torch.cuda.mem_get_info(device))
72    tag = f"[eval:{cfg.process.name}] d={d} K={K} budgets={budgets(cfg)}"
73    print(f"{tag}: est. peak {need:.1f} GB, GPU free {free:.1f}/{total:.1f} GB")
74    if need > 0.92 * free:
75        raise MemoryError(f"{tag}: estimated peak {need:.1f} GB exceeds free GPU memory {free:.1f} GB; "
76                          f"lower sweep.anchors, K or eval.n_eval_per_mode (or one eval job per GPU)")

Cell files: the permanent recordlines 79–107

Each cell's results live in cells/d<d>_K<K>_s<seed>.json as a list of rows, one per (budget, predictor). Saved atomically (temporary file + rename). _key identifies a row; row_order sorts rows in one fixed order so that files built in any order end up identical.

 80def cell_path(out_dir, d, K, seed):
 81    return os.path.join(out_dir, "cells", f"d{int(d)}_K{int(K)}_s{int(seed)}.json")

 84def _load_cell(path):
 85    if not os.path.exists(path):
 86        return []
 87    with open(path) as f:
 88        return json.load(f)["rows"]

 91def _save_cell(path, rows):
 92    os.makedirs(os.path.dirname(path), exist_ok=True)
 93    tmp = f"{path}.{os.getpid()}.tmp"
 94    with open(tmp, "w") as f:
 95        json.dump({"rows": rows}, f)
 96    os.replace(tmp, path)                                   # atomic: never half a file

 98
 99def _key(r):
100    return int(r["n_per_mode"]), r["model"]
101
102
103def row_order(cfg):
104    """Sort key: (d, K, seed, budget, predictor in config order, others after by name)."""
105    names = [s["name"] for s in _specs(cfg)]
106    rank = lambda m: (names.index(m), m) if m in names else (len(names), m)
107    return lambda r: (int(r["d"]), int(r["K"]), int(r["seed"]), int(r["n_per_mode"]), rank(r["model"]))

_ground_truth(): what the learned model really doeslines 110–121

Makes the evaluation seeds (repeat seed + 1, the same as train.py used) and takes their fates from train.py's cache, or computes and caches them if the cache is missing.

111def _ground_truth(cfg, proc, model, ck, d, K, seed, device):
112    """The eval seeds and their fates under the learned sampler (from train.py's cache when
113    it is there, otherwise computed and cached now)."""

eval_one(): one cell, start to finishlines 124–200

The heart of the project.

  1. What is missing? Compare the wanted (budget, predictor) rows with the cell file. Nothing missing → return straight away. eval.force=true recomputes the requested rows.
  2. Load the trained model and build two processes on the same mixture: proc with the model's T (the learned sampler) and proc_true with T_true (the exact field).
  3. Ground truth, then free the network (only its fates are needed from here on).
  4. Calibration seeds: 5 000 seeds (repeat seed + 2) labelled by the exact field. altered_knn uses them to choose its hallucination threshold.
  5. For each budget:
    • ball + shell anchors → backtrack to seeds (step 1–2), in place to save memory;
    • ring anchors too, if altered_knn is among the predictors;
    • for each predictor: fit (step 3), calibrate if needed, predict the evaluation seeds' fates, compute the scores (steps 4–5) and store a row;
    • free the anchors before the next, bigger budget.
  6. Merge new rows with the cached ones, sort, save the cell file.

A row records the cell, the budget, the number of anchors, the predictor, the learned sampler's hallucination rate (hall_gt), the counts, the time taken and every score.

124def eval_one(cfg, d, K, seed, device):
125    """All rows of one cell: the cached ones plus the missing (budget, predictor) rows, which
126    are computed and saved. None when the cell has no checkpoint."""
127    process, variant = cfg.process.name, variant_of(cfg)
128    cpath = cell_path(sweep_dir(cfg.paths.output, cfg.run_id, process, cfg.process.T_true, variant),
129                      d, K, seed)
130    want = {(b, s["name"]) for b in budgets(cfg) for s in _specs(cfg)}
131    cached = _load_cell(cpath)
132    if bool(cfg.eval.force):
133        cached = [r for r in cached if _key(r) not in want]
134    todo = want - {_key(r) for r in cached}
135    if not todo:
136        return cached
137    path = ckpt_path(cfg.paths.checkpoints, process, d, K, seed, variant)
138    if not os.path.exists(path):
139        return None
140
141    model, ck = load_ckpt(path, device)
142    means_t, R99, variance = ck["means"], ck["R99"], ck["variance"]
143    sigma = float(variance ** 0.5)
144    weights = ck.get("weights")                              # the GMM the model was trained on
145    w_row = [round(float(x), 4) for x in weights] if weights is not None else None
146    proc = make_process(process, means_t, variance, ck["T"], device, cfg, weights)
147    proc_true = make_process(process, means_t, variance, int(cfg.process.T_true), device, cfg, weights)
148
149    X_te, gt = _ground_truth(cfg, proc, model, ck, d, K, seed, device)
150    del model
151    if device.type == "cuda":
152        torch.cuda.empty_cache()
153    cell = {"hall_gt": float((gt == -1).float().mean()), "n_eval": int(gt.numel()),
154            "n_mode": int((gt >= 0).sum()), "n_hall": int((gt == -1).sum()), "weights": w_row}
155
156    a = cfg.anchors
157    # a small set of seeds labelled by the exact field, used to calibrate altered_knn's cut
158    X_cal = proc.seeds(int(a.n_calibrate), d, seed + 2)
159    y_cal = proc_true.label(None, X_cal, R99)
160
161    rows = []
162    for b in budgets(cfg):
163        specs = [s for s in _specs(cfg) if (b, s["name"]) in todo]
164        if not specs:
165            continue
166        P, y = core.ball_anchors(means_t, R99, b, float(a.shell_frac), float(a.shell_sigma),
167                                 sigma, int(a.seed), device)                                 # step 1
168        A = proc_true.true_field_backtrack(P, inplace=True)                                  # step 2
169        del P
170        Aa = ya = wa = None
171        if any(s["arch"] == "altered_knn" for s in specs):
172            r = a.altered_knn
173            Pa, ya, wa = core.altered_knn_anchors(means_t, R99, b, int(r.n_rings), float(r.r_max),
174                                                  str(r.weight), float(r.w_min), sigma=sigma,
175                                                  seed=int(a.seed), device=device)
176            Aa = proc_true.true_field_backtrack(Pa, inplace=True)
177            del Pa
178
179        for spec in specs:
180            t0 = time.time()
181            altered = spec["arch"] == "altered_knn"
182            nets = (fate.train_ensemble(Aa, ya, K, spec, device, w=wa) if altered
183                    else fate.train_ensemble(A, y, K, spec, device))                          # step 3
184            if altered and spec["threshold"] == "auto":
185                for net in nets:
186                    net.calibrate(X_cal, y_cal)
187            met = fate.fate_metrics(fate.predict_fate(nets, X_te), gt)                        # steps 4-5
188            rows.append({"seed": seed, "d": d, "K": K, "n_per_mode": b,
189                         "n_anchors": int(nets[0].X.shape[0]) if hasattr(nets[0], "X") else int(A.shape[0]),
190                         "model": spec["name"], "arch": spec["arch"], "hall_gt": cell["hall_gt"],
191                         "n_eval": cell["n_eval"], "n_mode": cell["n_mode"], "n_hall": cell["n_hall"],
192                         "weights": w_row, "secs": round(time.time() - t0, 1), **met})
193            del nets
194        del A, Aa                                   # free this budget before the next (bigger) one
195        if device.type == "cuda":
196            torch.cuda.empty_cache()
197
198    rows = sorted(cached + rows, key=row_order(cfg))
199    _save_cell(cpath, rows)
200    return rows

aggregate(): mean ± std over repeat seedslines 203–225

Groups rows by (d, K, budget, predictor) and replaces each score by its mean over the repeat seeds, plus a _std companion (population standard deviation). Missing values (NaN) are ignored rather than poisoning the average.

203# ---- aggregation and results files -----------------------------------------------------------
204AGG_KEYS = ("hall_gt",) + tuple(fate.METRICS)     # per-seed scalars reported as mean +- std
205
206
207def aggregate(results):
208    """One row per (d, K, budget, model): each AGG_KEYS value becomes its mean over seeds with a
209    <key>_std companion (population std), plus n_seeds, the seeds and their mixing weights."""
210    groups = {}
211    for r in results:
212        groups.setdefault((r["d"], r["K"], int(r["n_per_mode"]), r["model"]), []).append(r)
213    out = []
214    for (d, K, b, model), rs in groups.items():
215        rs = sorted(rs, key=lambda r: r["seed"])
216        row = {"d": d, "K": K, "n_per_mode": b, "n_anchors": rs[0]["n_anchors"],
217               "model": model, "arch": rs[0]["arch"], "n_seeds": len(rs),
218               "seeds": [r["seed"] for r in rs], "weights": [r.get("weights") for r in rs]}
219        for k in AGG_KEYS:
220            v = np.array([r[k] for r in rs], dtype=np.float64)
221            ok = np.isfinite(v).any()
222            row[k] = float(np.nanmean(v)) if ok else float("nan")
223            row[k + "_std"] = float(np.nanstd(v)) if ok else float("nan")
224        out.append(row)
225    return out

run(): the whole stagelines 242–262

For each (d, K): preflight check, evaluate every repeat seed, print the summary. A cell without a checkpoint is reported and skipped.

With eval.part=true (what scripts/main.sh uses, one job per d) it stops after writing cell files; a single later merge builds the results. Otherwise it merges straight away.

242def run(cfg):
243    device = core.get_device(cfg.device)
244    process = cfg.process.name
245    n_rows = 0
246    for d in cfg.sweep.d:
247        for K in cfg.sweep.K:
248            preflight(cfg, int(d), int(K), device)
249            cell = []
250            for seed in core.seed_list(cfg):
251                rows = eval_one(cfg, int(d), int(K), seed, device)
252                if rows is None:
253                    print(f"[eval:{process}] d={d:>2} K={K:>2} seed={seed:<4} -> no checkpoint, skipped")
254                else:
255                    cell += rows
256            if cell:
257                n_rows += len(cell)
258                _console(process, d, K, cell, _primary(cfg))
259    if bool(cfg.eval.part):          # scripts/main.sh: one job per d, then a single `merge`
260        print(f"[eval:{process}] {n_rows} rows in cell files; run stages=[merge] to rebuild results.json")
261        return
262    merge(cfg)

_write_results(): the three results fileslines 265–295

  • results.json: everything: the sweep that is covered, every per-seed row and the aggregate. This is the only file visualize.py reads.
  • results.csv: the aggregate table (mean and std of each score).
  • results_per_seed.csv: one line per row, with the mixing weights.

merge(): rebuild the results from every cell filelines 298–313

Reads all cell files of this (process, variant, T_true), whichever invocation or machine wrote them, and rewrites the results files. Protected by a lock file because parallel jobs may call it at the same moment.

298def merge(cfg):
299    """Rebuild results.json / csv from every cell file of this (process, variant, T_true),
300    whichever invocation or machine wrote it. Locked: parallel evaluate jobs may all call it."""
301    process, variant = cfg.process.name, variant_of(cfg)
302    out_dir = sweep_dir(cfg.paths.output, cfg.run_id, process, cfg.process.T_true, variant)
303    os.makedirs(out_dir, exist_ok=True)
304    with open(os.path.join(out_dir, ".lock"), "w") as lk:
305        fcntl.flock(lk, fcntl.LOCK_EX)
306        results = sorted((r for p in glob.glob(os.path.join(out_dir, "cells", "*.json"))
307                          for r in _load_cell(p)), key=row_order(cfg))
308        if not results:
309            raise FileNotFoundError(f"[merge:{process}] no cell files under {out_dir}/cells")
310        cells = {(r["d"], r["K"], r["seed"]) for r in results}
311        print(f"[merge:{process}/{variant}] T={int(cfg.process.T_true)}: {len(cells)} cells, "
312              f"d={sorted({c[0] for c in cells})}, {len(results)} rows")
313        _write_results(cfg, out_dir, results)
