One interface, two processeslines 1–20

train.py and evaluate.py never ask "is this DDIM or flow?". They call five methods, and each process implements them:

methodwhat it does
train_closurea fresh network and its one-step training loss
sampleseeds → endpoints with the learned network
true_field_forwardseeds → endpoints with the exact field
true_field_backtrackendpoints → seeds with the exact field
seedsreproducible N(0, I) starting points

Adding a third process means writing one more subclass and registering it in factory.py.

Process: the shared partlines 23–57

  • The constructor stores the mode centres, the variance σ², the number of steps T and the mixing weights (plus their logarithms, which the exact field needs).
  • seeds(N, d, seed): N standard-normal points from their own generator, so seed 1 always gives the same points.
  • arch, n_train, optim_kwargs: read the network size, training-set size and recipe from the configuration.
  • label(model, X0, R99): seeds → fates. Pass model=None to use the exact field instead of the network.

DDIMProcesslines 14–26

Builds the noise schedule ᾱ for its own T. That is T_train for the learned sampler and T_true for the exact one, so the two schedules are different arrays (see the note on make_schedule). true_order chooses Heun (default) or Euler for the exact field.

train_closure just calls core.learned_closure.

sample(): run the learned samplerlines 28–37

From i = T−1 down to 1: ask the network for the noise at step i, take one DDIM step. Done in chunks of 50 000 seeds to bound memory. model.eval() and @torch.no_grad() make it pure inference.

28    @torch.no_grad()
29    def sample(self, model, X0, chunk=50000):
30        model.eval()
31        X = X0.clone()
32        for i in reversed(range(1, self.T)):
33            for s in range(0, X.shape[0], chunk):
34                xs = X[s:s + chunk]
35                eps = model(xs, torch.full((xs.shape[0],), i, dtype=torch.long, device=self.device))
36                X[s:s + chunk] = core._ddim_step(xs, eps, self.abar[i], self.abar[i - 1])
37        return X

Flow matching in one paragraphlines 1–15

Instead of adding and removing noise, flow matching learns a velocity field: at time t, which way and how fast should a point move so that, starting from noise at t = 0, it arrives at data at t = 1? With the "optimal transport" path used here, each training pair (noise x₀, data x₁) is joined by a straight line:

position ψ_t = (1 − (1 − σ_min)·t)·x₀ + t·x₁ velocity u = x₁ − (1 − σ_min)·x₀

Sampling integrates the learned velocity from t = 0 to t = 1 with an ODE solver.

 1"""processes/flow.py — flow matching with the optimal-transport path (Lipman et al. 2022, Ex. II).
 2
 3t = 0 is noise, t = 1 is data. With s_t = 1 - (1 - sigma_min) t:
 4    path    psi_t(x0) = s_t x0 + t x1                       (Eq. 22)
 5    target  u_t       = x1 - (1 - sigma_min) x0             (Eq. 23)
 6The network is a velocity field, integrated t: 0 -> 1 to sample. The exact field is the
 7marginal OT velocity of the GMM in closed form, keeping the within-mode variance (without it
 8the field is 1/sigma_min-stiff at t = 1 and the backtrack is not invertible).
 9"""

FlowOTProcess and its training steplines 18–47

The time grid is T evenly spaced points from 0 to 1. So unlike DDIM, a different T only changes the step size, never the start or end.

One training step: take data x₁ and noise x₀, a random time t, the point ψt on the line between them, and train the network to output the line's velocity. The network's time input is t rounded to the nearest grid index, so the same ScoreNet as DDIM can be used.

18class FlowOTProcess(Process):
19    name = "flow"
20
21    def __init__(self, means_t, variance, T, device, cfg, weights=None):
22        super().__init__(means_t, variance, T, device, cfg, weights)
23        p = cfg.process
24        self.sigma_min = float(p.sigma_min)
25        self.solver = str(p.solver)                             # learned sampler
26        self.true_solver = str(p.get("true_solver") or self.solver)   # exact field
27        self.ts = torch.linspace(0.0, 1.0, T, device=device)
28
29    def train_closure(self, K, d, batch, seed):
30        torch.manual_seed(seed)
31        model = core.ScoreNet(d, **self.arch(d)).to(self.device)
32        oms = 1.0 - self.sigma_min
33        g = core.step_generator(seed, self.device)
34        draw = core._minibatch(self.means_t, self.variance, batch, self.n_train(), seed,
35                               self.device, self.weights, g)
36
37        def step():
38            x1 = draw()
39            x0 = torch.randn(batch, d, generator=g, device=self.device)
40            t = torch.rand(batch, generator=g, device=self.device)
41            psi = (1 - oms * t)[:, None] * x0 + t[:, None] * x1            # Eq. 22
42            target = x1 - oms * x0                                         # Eq. 23
43            ti = (t * (self.T - 1)).round().long().clamp(0, self.T - 1)    # time-embedding index
44            return ((model(psi, ti) - target) ** 2).mean()
45
46        step.generator = g
47        return model, step

_step(): one ODE steplines 49–64

Four standard solvers: Euler (one velocity per step), midpoint and Heun (two), RK4 (four). More evaluations per step means more accuracy for the same number of steps. The learned sampler uses Euler by default and the exact field uses Heun.

49    # ---- ODE integration on the uniform grid self.ts ----
50    def _step(self, f, x, t, dt, solver):
51        if solver == "euler":
52            return x + dt * f(x, t)
53        if solver == "heun":
54            k1 = f(x, t)
55            return x + 0.5 * dt * (k1 + f(x + dt * k1, t + dt))
56        if solver == "midpoint":
57            return x + dt * f(x + 0.5 * dt * f(x, t), t + 0.5 * dt)
58        if solver == "rk4":
59            k1 = f(x, t)
60            k2 = f(x + 0.5 * dt * k1, t + 0.5 * dt)
61            k3 = f(x + 0.5 * dt * k2, t + 0.5 * dt)
62            k4 = f(x + dt * k3, t + dt)
63            return x + (dt / 6.0) * (k1 + 2 * k2 + 2 * k3 + k4)
64        raise ValueError(f"unknown solver {solver!r}")

_integrate(): run the solver over the whole gridlines 66–75

Forwards (t: 0 → 1, seed → data) or backwards (t: 1 → 0, data → seed) with a negative step, in chunks of 50 000 points.

66    def _integrate(self, f, X, chunk, solver, backward=False, inplace=False):
67        """Integrate dx/dt = f(x, t) over the grid, t: 0 -> 1 (or 1 -> 0 when backward)."""
68        dt = 1.0 / (self.T - 1)
69        X = X if inplace else X.clone()
70        steps = reversed(range(1, self.T)) if backward else range(self.T - 1)
71        for i in steps:
72            t = float(self.ts[i])
73            for s in range(0, X.shape[0], chunk):
74                X[s:s + chunk] = self._step(f, X[s:s + chunk], t, -dt if backward else dt, solver)
75        return X

_true_velocity(): the exact velocity of a Gaussian mixturelines 86–103

The flow version of true_score. At time t, a point from mode k is distributed as N(t·μk, vart·I) with vart = t²σ² + st². Given a position x, standard Gaussian conditioning gives the expected data point, and the velocity follows from it:

E[x₁ | x, mode k] = μ_k + gain · (x − t·μ_k), gain = t·σ² / var_t velocity(x, t) = (Σ_k r_k · E[x₁ | x, k] − (1 − σ_min)·x) / s_t

with responsibilities rk as before. The docstring explains why the within-mode variance σ² is kept: without it the field becomes extremely steep near t = 1 and the backward integration cannot undo the forward one.

 86    @torch.no_grad()
 87    def _true_velocity(self, x, t):
 88        """Marginal OT velocity (E[x1 | x_t = x] - (1 - sigma_min) x) / s_t of the GMM.
 89
 90        x_t | k ~ N(t mu_k, var_t I) with var_t = t^2 sigma^2 + s_t^2, so
 91        E[x1 | x, k] = mu_k + gain (x - t mu_k) with gain = t sigma^2 / var_t, and the modes are
 92        weighted by their posterior responsibilities r_k (mixing weights included)."""
 93        oms = 1.0 - self.sigma_min
 94        st = max(1.0 - oms * t, 1e-6)
 95        M = self.means_t
 96        var_t = t * t * self.variance + st * st
 97        logits = -torch.cdist(x, t * M) ** 2 / (2 * var_t)
 98        if self.logw is not None:
 99            logits = logits + self.logw
100        r = torch.softmax(logits, dim=1)
101        gain = t * self.variance / var_t
102        m_bar = (1 - t * gain) * (r @ M) + gain * x               # = sum_k r_k E[x1 | x, k]
103        return (m_bar - oms * x) / st
