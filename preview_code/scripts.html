The whole sweep on every GPUlines 1–20

Runs the full grid in three phases, each spread over all GPUs as a queue of small jobs: train (one job per cell), evaluate (one job per d), merge + visualize. Every setting is an environment variable, and every job is an ordinary python code/main.py ... call with overrides; conf/ is never edited.

./scripts/main.sh # the full grid DIMS="512" KS="2 4 8 16" PROCESSES=ddim ./scripts/main.sh # a slice SKIP_TRAIN=true ./scripts/main.sh # evaluation only GPUS="3" ./scripts/main.sh # only GPU 3
 1#!/usr/bin/env bash
 2# scripts/main.sh — the whole sweep, spread over every GPU. Everything is passed to
 3# code/main.py as Hydra overrides; conf/ is never edited.
 4#
 5# Three phases, each fanned out over all GPUs (a failed job is retried RETRIES times):
 6#   1) train     one job per (process, variant, d, K) cell; its NSEEDS seeds train together
 7#                -> checkpoints/<process>/<variant>/
 8#   2) evaluate  one job per (process, variant, T_true, d), several per GPU (each is small)
 9#                -> output/$RUN/<process>/<variant>/T<T>/cells/
10#   3) merge     one job per (process, variant, T_true): results.json + figures from all cells
11#
12# RUN names the run (default abc123). Re-running with the same RUN skips finished models and
13# result rows, so the sweep can be done in pieces (DIMS="16", later DIMS="32", ...) and ends
14# with the same files. Which predictors run is set in conf/config.yaml.
15#
16#   ./scripts/main.sh                                # the full grid
17#   DIMS="512" KS="2 4 8 16" PROCESSES=ddim ./scripts/main.sh
18#   TRAIN_ONLY=true ./scripts/main.sh                # phase 1 only
19#   SKIP_TRAIN=true ./scripts/main.sh                # phases 2-3 on the existing models
20#   DEVICE=cpu NGPU=2 DIMS="2" KS="2 4" TS="200" ANCHORS="[2000,10000]" ./scripts/main.sh

run_pool(): a tiny job schedulerlines 81–108

Takes the list JOBS ("log name|overrides") and keeps every GPU busy:

  1. Make a list of free slots (each GPU × jobs per GPU).
  2. While a slot is free and jobs remain, start the next job in the background on that GPU (CUDA_VISIBLE_DEVICES), retrying up to RETRIES times and keeping each failed log.
  3. Every 3 seconds, check which jobs finished and free their slots.
 81# ---- run the commands in JOBS[] ("logname|override args") across NGPU GPUs, $1 jobs per GPU ----
 82run_pool() {
 83  local PER=${1:-1}
 84  local FREE=() RPID=() RGPU=() NP=() NG=() i=0 done_n=0 total=${#JOBS[@]} gpu j pid g log args g0 k
 85  for ((k=0; k<PER; k++)); do for g0 in "${GPU_IDS[@]}"; do FREE+=("$g0"); done; done
 86  while [ $done_n -lt $total ]; do
 87    while [ ${#FREE[@]} -gt 0 ] && [ $i -lt $total ]; do
 88      gpu=${FREE[0]}; FREE=("${FREE[@]:1}")
 89      log="${JOBS[$i]%%|*}"; args="${JOBS[$i]#*|}"; i=$((i+1))
 90      echo ">>> [gpu $gpu] $log"
 91      ( for ((try=0; try<=RETRIES; try++)); do
 92          [ $try -gt 0 ] && { echo "  [retry $try] $log"; mv "$LOGDIR/$log" "$LOGDIR/${log%.log}.fail$try.log"; }
 93          CUDA_VISIBLE_DEVICES="$gpu" "$PY" code/main.py $args device="$DEVICE" > "$LOGDIR/$log" 2>&1 \
 94            && { echo "  [ok]   $log"; exit 0; }
 95        done; echo "  [FAIL] $log -> $LOGDIR/$log" ) &
 96      RPID+=("$!"); RGPU+=("$gpu")
 97    done
 98    NP=(); NG=()
 99    for j in "${!RPID[@]}"; do
100      pid=${RPID[$j]}; g=${RGPU[$j]}
101      if kill -0 "$pid" 2>/dev/null; then NP+=("$pid"); NG+=("$g")
102      else wait "$pid"; FREE+=("$g"); done_n=$((done_n + 1)); fi
103    done
104    RPID=(); RGPU=()
105    [ ${#NP[@]} -gt 0 ] && { RPID=("${NP[@]}"); RGPU=("${NG[@]}"); }
106    [ $done_n -lt $total ] && sleep 3
107  done
108}

One job per (process, variant, d, K), smallest cells first so that early results appear quickly. With more than one job per GPU the per-seed CUDA streams are switched off (see run_optimizers).

Submits the training array, then the evaluation array with --dependency=afterok so that it starts only when every training task has succeeded. Both share one RUN_ID.

 2# scripts/slurm/submit.sh — submit the unweighted sweep: train array, then eval array after it.
 3#   ./scripts/slurm/submit.sh            # from the repo root
 4# Both arrays share RUN_ID so results land in output/<RUN_ID>/<process>/unweighted/T<T>/.
 5set -euo pipefail

48| `%8` in `--array=0-47%8` | how many cells to run concurrently |

50## 4. Submit and watch
51
52```bash
53./scripts/slurm/submit.sh                 # prints both job ids and the run_id
54squeue -u $USER                           # PD = pending, R = running, CG = completing
55sacct -j <train_jobid> --format=JobID,State,Elapsed,MaxRSS -X   # per-task state, wall time, RAM
56tail -f slurm/atlas-train_<train_jobid>_0.out
57scancel <jobid>                           # whole array;  scancel <jobid>_7  one task
58```

60Outputs: checkpoints in `data/<process>/unweighted/checkpoints/`, ground truth in
61`data/<process>/unweighted/gt_cache/`, results in `output/<run_id>/<process>/unweighted/T<T>/`.

63## Resubmitting
64
65Training is idempotent (`train.force_retrain=false`): a cell whose 3 checkpoints exist is
66skipped, so after a time-limit kill just resubmit the failed indices, e.g.
67
68```bash
69sacct -j <train_jobid> -X --format=JobID,State | grep -v COMPLETED       # find them
70sbatch --array=23,47 --export=ALL,RUN_ID=<run_id> scripts/slurm/train.sbatch
71sbatch --export=ALL,RUN_ID=<run_id> scripts/slurm/eval.sbatch             # then eval
72```
73
74Task index -> cell: `i = process_index*24 + d_index*4 + K_index` with processes (ddim, flow),
75d in (2,4,8,16,32,64), K in (2,4,8,16); so 0..23 are ddim, 24..47 flow, and K varies fastest.
