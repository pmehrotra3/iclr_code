What this file islines 1–30

The single entry point. You never import it; you run it:

python code/main.py # the sweep in conf/ python code/main.py sweep.d=[16,64] # change any setting on the command line python code/main.py stages=[visualize] # only redraw the figures

Line 18 sets a PyTorch memory option before torch is imported (it has no effect afterwards). The evaluation stage holds a few very large anchor tensors, and this option stops GPU memory from fragmenting around them.

Line 25 lets the stage modules import each other by plain name (import core) however the script is started.

main(): load settings, check the run, run the stageslines 40–63

Hydra builds the configuration: it reads conf/config.yaml, pulls in one file from each group (process, data, train, …) and applies your command-line overrides. The result is one nested object, cfg, passed to every stage.

  1. Print the full configuration (so every log file records what was run).
  2. Reject unknown stage names before doing any work.
  3. runstate.check_and_record makes sure this invocation computes things the same way as earlier invocations of the same run_id, and logs it.
  4. Run each stage.
40@hydra.main(version_base=None, config_path="../conf", config_name="config")
41def main(cfg: DictConfig) -> None:
42    print("=" * 70)
43    print(OmegaConf.to_yaml(cfg))
44    print("=" * 70)
45    for stage in cfg.stages:
46        if stage not in STAGES:
47            raise ValueError(f"unknown stage '{stage}'. choose from {list(STAGES)}")
48    # same run_id = same run: check the settings against output/<run_id>/run.json and log the
49    # invocation (its resolved config goes to output/<run_id>/invocations/)
50    try:
51        overrides = list(HydraConfig.get().overrides.task)
52    except Exception:
53        overrides = []
54    rd = runstate.check_and_record(cfg, overrides)
55    print(f"run '{cfg.run_id}' -> {rd}")
56    for stage in cfg.stages:
57        print(f"\n>>> STAGE: {stage}\n" + "-" * 40)
58        STAGES[stage](cfg)

Why runs have nameslines 1–20

A big sweep takes days and is often done in pieces: d = 2…64 today, d = 128 tomorrow, another machine for d = 512, a new predictor next week. All the pieces write into the same folder, output/<run_id>/, and every stage skips work that is already there.

That is only safe if every piece computes a cell the same way. So the first invocation writes its settings to run.json, and later ones are compared against it. Settings that only choose which cells to compute (d, K, how many seeds, the device…) may differ; settings that change a result (training steps, learning rate, a predictor's k…) may not.

Which settings may differ between pieceslines 22–25

  • _SELECT: top-level keys that only choose what to compute or where. Ignored completely.
  • _DROP: per-invocation switches such as force_retrain. Ignored wherever they appear in the tree.

Everything else is part of the run's identity.

22# top-level keys that only choose what to compute (plus data.weighted, the variant)
23_SELECT = {"stages", "run_id", "device", "seed", "n_seeds", "sweep", "paths", "strict_run", "hydra"}
24# per-invocation switches, ignored wherever they appear
25_DROP = {"root", "force_retrain", "force", "graph_streams", "part"}

Removes the _DROP keys from a nested dict, at any depth.

32def _strip(x):

identity(): the settings a run is made oflines 36–47

Turns the configuration into the record stored in run.json, in three parts:

  • config: data, training, evaluation, anchors… (minus _SELECT). data.weighted is removed because the weighted and unweighted variants are allowed in the same run (they go to different folders).
  • process: the DDIM or flow settings, keyed by process name, with T_true removed (different T_true values also go to different folders).
  • predictors: each predictor's final settings (shared defaults + its own).

Keying process and predictors by name is what lets you add flow or a new predictor to an existing run later.

36def identity(cfg):
37    """The settings every invocation of a run must share, split into config / process /
38    predictors so a new process or predictor can be added to a run later."""
39    c = OmegaConf.to_container(cfg, resolve=True)
40    proc = _strip(c["process"])
41    proc.pop("T_true", None)
42    shared = c["classifier"].get("_shared") or {}
43    config = {k: _strip(v) for k, v in c.items() if k not in _SELECT | {"process", "classifier"}}
44    config["data"].pop("weighted", None)
45    return {"config": config,
46            "process": {proc["name"]: proc},
47            "predictors": {n: {**shared, **(m or {})} for n, m in c["classifier"]["models"].items()}}

_diff() and _merge(): compare and extendlines 50–63

_diff walks two nested dicts and lists every value that both have but that differs. A key present on only one side (a new predictor, a setting added to the code later) is not a difference. _merge keeps the old record and adds whatever only the new one has.

50def _diff(old, new, path=""):
51    """[(path, old, new)] for values both sides have that differ; a key only one side has
52    (a new predictor, a setting added to the config later) is not a difference."""
53    if isinstance(old, dict) and isinstance(new, dict):
54        return [x for k in old.keys() & new.keys() for x in _diff(old[k], new[k], f"{path}.{k}" if path else k)]
55    return [] if old == new else [(path, old, new)]
56
57
58def _merge(old, new):
59    """`old` plus whatever only `new` has (new processes / predictors)."""
60    if isinstance(old, dict) and isinstance(new, dict):
61        return {**{k: _merge(v, new[k]) if k in new else v for k, v in old.items()},
62                **{k: v for k, v in new.items() if k not in old}}
63    return old

settings_diff()lines 66–70

Applies _diff to the three parts and labels each difference, for example config.train.base_steps.

66def settings_diff(old, new):
67    """Differences between two run.json records, as (section.path, old, new)."""
68    return [(f"{name}.{p}" if p else name, a, b)
69            for name, key in (("config", "config"), ("process", "process"), ("predictor", "predictors"))
70            for p, a, b in _diff(old[key], new[key])]

check_and_record(): the gatekeeperlines 73–106

  1. Open run.json with an exclusive file lock, because scripts/main.sh starts many jobs at the same moment and they must not overwrite each other.
  2. If the file already has settings and any differ, stop with a message that lists each one:
    run 'abc123' was made with different settings: config.train.base_steps: run has 30000, this invocation 151 -> use a new run_id, or strict_run=false to mix on purpose
  3. Otherwise save the merged record (adding new processes or predictors) with updated time stamps.
  4. Save this invocation's full configuration in invocations/ and append one line to history.log.
 73def check_and_record(cfg, overrides=()):
 74    """Compare this invocation with output/<run_id>/run.json (the first invocation creates it),
 75    record any new process / predictor, and log the invocation. Returns the run folder."""
 76    rd = run_dir(cfg)
 77    os.makedirs(rd, exist_ok=True)
 78    new = identity(cfg)
 79    now = time.strftime("%Y-%m-%d %H:%M:%S")
 80    with open(os.path.join(rd, "run.json"), "a+") as f:
 81        fcntl.flock(f, fcntl.LOCK_EX)                  # scripts/main.sh starts jobs in parallel
 82        f.seek(0)
 83        text = f.read()
 84        if text.strip():
 85            old = json.loads(text)
 86            diffs = settings_diff(old, new)
 87            if diffs and cfg.strict_run:
 88                fcntl.flock(f, fcntl.LOCK_UN)
 89                lines = "\n".join(f"    {p}: run has {a!r}, this invocation {b!r}" for p, a, b in diffs)
 90                raise ValueError(f"run '{cfg.run_id}' was made with different settings ({rd}/run.json):\n"
 91                                 f"{lines}\n  -> use a new run_id, or strict_run=false to mix on purpose")
 92            record = {**_merge(old, new), "created": old.get("created"), "updated": now}
 93        else:
 94            record = {**new, "created": now, "updated": now}
 95        f.seek(0); f.truncate()
 96        json.dump(record, f, indent=2)
 97        fcntl.flock(f, fcntl.LOCK_UN)
 98
 99    # keep the full resolved config of every invocation, and a one-line history
100    stamp = time.strftime("%Y-%m-%d_%H-%M-%S")
101    os.makedirs(os.path.join(rd, "invocations"), exist_ok=True)
102    with open(os.path.join(rd, "invocations", f"{stamp}_{os.getpid()}_{'_'.join(cfg.stages)}.yaml"), "w") as f:
103        f.write(OmegaConf.to_yaml(cfg, resolve=True))
104    with open(os.path.join(rd, "history.log"), "a") as f:
105        f.write(f"{stamp}  pid={os.getpid()}  stages=[{','.join(cfg.stages)}]  {' '.join(overrides)}\n")
106    return rd
