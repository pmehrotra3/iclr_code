Stage 1 in a nutshelllines 1–25

For every (d, K) in the sweep and every repeat seed: place the modes, train a network on samples of the mixture, check that it rarely hallucinates, save it, and record where it sends the evaluation seeds (the ground truth used by stage 2).

A checkpoint that already exists (with the right T) is reused, so the stage can be re-run safely at any time.

checkpoints/<process>/<variant>/ checkpoints/model_d<d>_K<K>_s<seed>.pt the trained network + everything about its cell gt_cache/d<d>_K<K>_s<seed>.pt fates of the evaluation seeds under it manifest.json one summary line per model

Paths: where everything is storedlines 28–58

Small helpers shared by the other stages so that every file name is built in exactly one place:

  • variant_of: "weighted" or "unweighted".
  • sweep_dir: output/<run_id>/<process>/<variant>/T<T_true>, where results go. resolve_sweep_dir returns it only if it already has results.
  • ckpt_path, gt_cache_path: the two files per trained model.
  • n_eval_for: 50 000 × K evaluation seeds, so every mode gets about the same number whatever K is (K = 2 → 100 000, K = 16 → 800 000).

_save_atomic(): never half a filelines 61–66

Saves to a temporary name first, then renames. A rename is instantaneous, so if the job is killed mid-save the old file (or no file) remains, never a corrupt half-written one that a later resume would trust.

61def _save_atomic(obj, path):
62    """torch.save via a temporary file: an interrupted save never leaves half a file."""
63    os.makedirs(os.path.dirname(path), exist_ok=True)
64    tmp = f"{path}.tmp{os.getpid()}"
65    torch.save(obj, tmp)
66    os.replace(tmp, path)

The ground-truth cachelines 69–86

Stores the fate of each evaluation seed plus what it was computed with. load_gt_cache only accepts a cache made for the same number of seeds and the same repeat seed; anything else (or an unreadable file) counts as missing and is recomputed.

69def save_gt_cache(data_dir, sampler, d, K, gt, n_eval, T_train, R99, seed, variant="unweighted"):
70    _save_atomic({"gt": gt.detach().cpu(), "n_eval": int(n_eval), "seed": int(seed),
71                  "T_train": int(T_train), "R99": float(R99)},
72                 gt_cache_path(data_dir, sampler, d, K, seed, variant))
73
74
75def load_gt_cache(data_dir, sampler, d, K, n_eval, seed, device, variant="unweighted"):
76    """Cached fate labels on `device` if present and made for (n_eval, seed), else None."""
77    p = gt_cache_path(data_dir, sampler, d, K, seed, variant)
78    if not os.path.exists(p):
79        return None
80    try:
81        blob = torch.load(p, map_location=device, weights_only=False)
82    except Exception:
83        return None
84    if int(blob.get("n_eval", -1)) != int(n_eval) or int(blob.get("seed", -999)) != int(seed):
85        return None
86    return blob["gt"].to(device)

_git_commit(): which code made this modellines 89–99

The current commit hash, with "-dirty" if there are uncommitted changes. Saved inside every checkpoint so you can always tell which version of the code trained it.

89def _git_commit():
90    """HEAD hash (+ '-dirty' with uncommitted changes), or None outside a repository."""
91    here = os.path.dirname(os.path.abspath(__file__))
92    try:
93        h = subprocess.check_output(["git", "rev-parse", "HEAD"], stderr=subprocess.DEVNULL,
94                                    cwd=here).decode().strip()
95        dirty = subprocess.run(["git", "diff", "--quiet"], stderr=subprocess.DEVNULL,
96                               cwd=here).returncode != 0
97        return h + ("-dirty" if dirty else "")
98    except Exception:
99        return None

Geometry of one celllines 102–117

_cell_geometry sets up one repeat: the sphere radius is data.radius × √(d/2) (2.0 at d = 2, 11.3 at d = 64, 32 at d = 512) so the modes stay well apart as d grows; then the centres, R99 and the mixing weights. If the modes cannot be placed it raises ModePlacementError, and the cell is skipped instead of crashing the sweep.

102# ---- one cell --------------------------------------------------------------------------------
103class ModePlacementError(RuntimeError):
104    """The (d, K, R, sigma) geometry cannot be placed: the cell is skipped."""
105
106
107def _cell_geometry(cfg, d, K, seed, device):
108    """(means, min_sep, R99, mixing weights) of one repeat. The sphere radius grows like
109    sqrt(d/2) (d=2 -> data.radius) so the modes stay resolvable as d grows."""
110    sigma = cfg.data.sigma
111    try:
112        means_t, min_sep = core.sample_modes(K, d, float(cfg.data.radius) * (d / 2.0) ** 0.5, sigma,
113                                             cfg.data.m_mult, seed=seed, device=device)
114    except RuntimeError as e:
115        raise ModePlacementError(str(e)) from e
116    weights = core.mode_weights(K, seed, bool(cfg.data.weighted), device=device, base_seed=int(cfg.seed))
117    return means_t, float(min_sep), core.r99(d, sigma, cfg.data.mass_q), weights

_save_cell(): write the checkpoint and the ground truthlines 120–143

A checkpoint holds far more than weights: the mode centres and weights, R99, σ, T, the hallucination rate measured at the end of training, whether it converged, how many steps and attempts it took, the network size, the entire configuration and the git commit. Evaluation needs nothing else to rebuild the cell.

Then it runs the new model on the evaluation seeds (repeat seed + 1), labels the endpoints with label_fate and caches them. If that fails (for example out of memory), evaluate.py simply recomputes it later.

120def _save_cell(cfg, d, K, seed, proc, model, means_t, min_sep, R99, hall, used_steps, attempts,
121               weights):
122    """Write the checkpoint (with its full config and git commit, for provenance) and cache the
123    learned sampler's ground truth for the eval seeds (the same ones evaluate.py uses)."""
124    sampler, variant, sigma, T = cfg.process.name, variant_of(cfg), cfg.data.sigma, cfg.process.T_train
125    path = ckpt_path(cfg.paths.checkpoints, sampler, d, K, seed, variant)
126    converged = hall <= cfg.train.hall_target
127    ckpt = {"state_dict": model.state_dict(), "sampler": sampler, "d": d, "K": K, "T": T, "seed": seed,
128            "means": means_t.cpu(), "weights": weights.cpu(), "weighted": variant == "weighted",
129            "R99": R99, "sigma": sigma, "variance": sigma ** 2, "min_sep": min_sep,
130            "hall_rate": hall, "converged": converged, "steps": used_steps, "attempts": attempts,
131            "arch": proc.arch(d), "config": OmegaConf.to_container(cfg, resolve=True),
132            "run_id": str(cfg.run_id), "git_commit": _git_commit(),
133            "created": time.strftime("%Y-%m-%d %H:%M:%S")}
134    if sampler == "flow":
135        ckpt["flow"] = {"sigma_min": float(cfg.process.sigma_min), "solver": str(cfg.process.solver)}
136    _save_atomic(ckpt, path)
137    try:
138        n_eval = n_eval_for(cfg, K)
139        gt = core.label_fate(proc.sample(model, proc.seeds(n_eval, d, seed + 1)), means_t, R99)
140        save_gt_cache(cfg.paths.checkpoints, sampler, d, K, gt, n_eval, T, R99, seed, variant)
141    except Exception as e:                        # evaluate.py recomputes it on a cache miss
142        print(f"[train:{sampler}] gt cache skipped d={d} K={K} seed={seed}: {e}")
143    return path, converged

train_cell(): train every missing model of one (d, K)lines 153–203

  1. Skip what exists. A checkpoint with the right T is reused. A checkpoint made with another T is retrained.
  2. Set up geometry for each remaining repeat seed.
  3. How long to train. The number of steps grows with d and K:
    steps = base_steps × (1 + d/16) × (1 + K/16) d=2, K=2 → 37 968 d=64, K=16 → 300 000 d=16, K=8 → 90 000 d=512, K=16 → 1 980 000
  4. Train all pending seeds together (one CUDA graph; see run_optimizers).
  5. Probe. Sample 10 000 fresh seeds (repeat seed + 7) and measure the hallucination rate. Above hall_target = 1.5%? Train that seed again from scratch with 1.7× more steps. At most max_attempts = 2 tries; a model that still misses is saved but flagged not_converged.
  6. Save every model with _save_cell and return one summary per seed.
153def train_cell(cfg, d, K, seeds, device):
154    """Train every missing repeat of the (d, K) cell; returns {seed: summary}."""
155    sampler, T = cfg.process.name, cfg.process.T_train
156    out, cells = {}, {}
157    for seed in seeds:
158        path = ckpt_path(cfg.paths.checkpoints, sampler, d, K, seed, variant_of(cfg))
159        if os.path.exists(path) and not cfg.train.force_retrain:
160            ck_T = _ckpt_T(path)
161            if ck_T == T:
162                out[seed] = {"d": d, "K": K, "seed": seed, "path": path, "status": "cached"}
163                continue
164            print(f"[train:{sampler}] d={d} K={K} seed={seed}: checkpoint has T={ck_T}, "
165                  f"want T_train={T} -> retraining")
166        try:
167            means_t, min_sep, R99, weights = _cell_geometry(cfg, d, K, seed, device)
168        except ModePlacementError as e:
169            out[seed] = {"d": d, "K": K, "seed": seed, "status": "skipped", "reason": str(e)}
170            continue
171        cells[seed] = {"means": means_t, "min_sep": min_sep, "R99": R99, "weights": weights,
172                       "proc": make_process(sampler, means_t, cfg.data.sigma ** 2, T, device, cfg, weights)}
173
174    steps = int(cfg.train.base_steps * (1 + d / 16) * (1 + K / 16))
175    t0 = time.time()
176    pending, done = list(cells), {}               # done: seed -> (model, hall, steps, attempts)
177    for attempt in range(int(cfg.train.max_attempts)):
178        if not pending:
179            break
180        models, closures = zip(*(cells[s]["proc"].train_closure(K, d, cfg.train.batch, s) for s in pending))
181        models = core.run_optimizers(list(models), list(closures), steps, cfg.train.lr,
182                                     **cells[pending[0]]["proc"].optim_kwargs())
183        still = []
184        for seed, model in zip(pending, models):
185            c = cells[seed]
186            Xf = c["proc"].sample(model, c["proc"].seeds(cfg.train.probe_n, d, seed + 7))
187            hall = float((core.label_fate(Xf, c["means"], c["R99"]) == -1).float().mean())
188            done[seed] = (model, hall, steps, attempt + 1)
189            if hall > cfg.train.hall_target:
190                still.append(seed)
191        pending = still
192        steps = int(steps * cfg.train.step_growth)
193
194    for seed, (model, hall, used_steps, attempts) in done.items():
195        c = cells[seed]
196        path, converged = _save_cell(cfg, d, K, seed, c["proc"], model, c["means"], c["min_sep"],
197                                     c["R99"], hall, used_steps, attempts, c["weights"])
198        out[seed] = {"d": d, "K": K, "seed": seed, "path": path,
199                     "status": "trained" if converged else "not_converged", "hall_rate": hall,
200                     "converged": converged, "steps": used_steps, "attempts": attempts,
201                     "net": core.net_size(d, cfg), "width": c["proc"].arch(d)["h"],
202                     "secs": round(time.time() - t0, 1)}          # wall time of the whole cell
203    return out

run(): the whole stagelines 206–243

Loops over every d and K of the sweep, prints one line per model, then merges the summaries into manifest.json under a file lock (parallel jobs write the same file). It ends with a warning if any model stayed above the hallucination target, because then that cell's results reflect a badly trained model rather than the geometry being studied.

206def run(cfg):
207    device = core.get_device(cfg.device)
208    sampler, variant = cfg.process.name, variant_of(cfg)
209    manifest, n_bad = {}, 0
210    for d in cfg.sweep.d:
211        for K in cfg.sweep.K:
212            seeds = core.seed_list(cfg)
213            infos = train_cell(cfg, int(d), int(K), seeds, device)
214            for seed in seeds:
215                info = infos[seed]
216                manifest[f"{d}_{K}_s{seed}"] = info
217                line = f"[train:{sampler}/{variant}] d={d:>2} K={K:>2} seed={seed:<4} -> {info['status']}"
218                if "hall_rate" in info:
219                    line += (f" hall={info['hall_rate']:.4f} steps={info['steps']} attempts={info['attempts']}"
220                             f" net={info['net']}/{info['width']} {info['secs']}s")
221                if info["status"] == "not_converged":
222                    line += f"  ** above hall_target={cfg.train.hall_target} **"
223                    n_bad += 1
224                print(line)
225
226    # one manifest per (process, variant), merged under a lock (parallel jobs of scripts/main.sh)
227    mpath = os.path.join(sampler_dir(cfg.paths.checkpoints, sampler, variant), "manifest.json")
228    os.makedirs(os.path.dirname(mpath), exist_ok=True)
229    with open(mpath, "a+") as f:
230        fcntl.flock(f, fcntl.LOCK_EX)
231        f.seek(0)
232        try:
233            merged = json.load(f)
234        except ValueError:
235            merged = {}
236        merged.update(manifest)
237        f.seek(0); f.truncate()
238        json.dump(merged, f, indent=2)
239        fcntl.flock(f, fcntl.LOCK_UN)
240    print(f"[train:{sampler}] manifest written: {mpath}")
241    if n_bad:
242        print(f"[train:{sampler}] WARNING: {n_bad} model(s) above hall_target: their results "
243              f"reflect training error, not sampler geometry")
