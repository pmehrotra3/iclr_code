When a run is split across machineslines 1–37

For example d ≤ 256 on the lab server and d = 512 on a cluster, both with the same run_id and settings. Copy the other machine's checkpoints/ and output/ into one folder, then:

python code/combine.py /tmp/other --dry-run # report only python code/combine.py /tmp/other # merge, then rebuild results and figures

The result is the same as if one machine had done everything. The one rule it never breaks: results computed from one model are never mixed with a different model of the same cell.

 1"""combine.py — fold a run built on ANOTHER machine into this machine's run of the same name.
 2
 3A run can be built on several machines at once (e.g. d <= 256 here, d = 512 elsewhere) with the
 4same run_id and settings. Copy the other machine's checkpoints/ and output/<run_id>/ into one
 5folder, keeping those two names, then:
 6
 7    rsync -a OTHER:iclr_code/checkpoints OTHER:iclr_code/output /tmp/other/
 8    python code/combine.py /tmp/other --dry-run      # report only
 9    python code/combine.py /tmp/other                # merge into ./checkpoints and ./output/<run_id>
10
11Steps:
12  1. settings   the two run.json files must agree (the check every invocation does; --force to
13                combine anyway); processes / predictors new on the other side are added
14  2. conflicts  a (process, variant, d, K, seed) model trained on BOTH machines with different
15                weights: this side's model is kept, and nothing the other side derived from its
16                own model (gt cache, cell rows) comes over, so results never mix two models
17  3. files      every file this side lacks is copied (models, gt caches, cell files, logs,
18                invocations); cells/*.json of the same cell get the union of their rows (this
19                side wins a row both have); manifest.json and history.log get the union
20  4. rebuild    results.json / csv and the figures of every <process>/<variant>/T<T>/, from all
21                cell files (--no-rebuild skips it). The other side's results.* / *.png are
22                never copied.
23"""

Safe file writinglines 42–56

_copy and _write_json write to a temporary file and rename it (atomic); in dry-run mode they do nothing.

42def _copy(src, dst, dry):
43    if not dry:
44        os.makedirs(os.path.dirname(dst), exist_ok=True)
45        tmp = f"{dst}.{os.getpid()}.tmp"
46        shutil.copy2(src, tmp)

50def _write_json(path, obj, dry):
51    if not dry:
52        os.makedirs(os.path.dirname(path), exist_ok=True)
53        tmp = f"{path}.{os.getpid()}.tmp"
54        with open(tmp, "w") as f:
55            json.dump(obj, f, indent=2)
56        os.replace(tmp, path)

_relocate()lines 59–66

The other machine's manifest stores absolute paths such as /home/them/iclr_code/checkpoints/…; this rewrites them to point at this machine's checkpoints/.

59def _relocate(manifest, dst_root):
60    """Point the other machine's absolute checkpoint paths at this machine's checkpoints/."""
61    tag = os.sep + "checkpoints" + os.sep
62    for e in manifest.values():
63        p = e.get("path") if isinstance(e, dict) else None
64        if p and tag in p:
65            e["path"] = os.path.join(dst_root, "checkpoints", p.split(tag, 1)[1])
66    return manifest

_same_model(): are these the same network?lines 69–76

First a byte-for-byte comparison (fast). If the files differ, it loads both and compares the weights tensor by tensor, because two saves of the same model can differ in metadata such as the creation time.

69def _same_model(a, b):
70    """Identical bytes, or identical weights (metadata such as 'created' may differ)."""
71    if filecmp.cmp(a, b, shallow=False):
72        return True
73    import torch
74    sa = torch.load(a, map_location="cpu", weights_only=False)["state_dict"]
75    sb = torch.load(b, map_location="cpu", weights_only=False)["state_dict"]
76    return sa.keys() == sb.keys() and all(torch.equal(sa[k], sb[k]) for k in sa)

Step 1: same settings?lines 79–107

Compares the two run.json files with the same check every invocation does (runstate.settings_diff). Different settings mean different experiments, so it refuses unless you pass --force. New processes or predictors from the other side are added.

 79def check_settings(src_run, dst_run, force, dry):
 80    """Step 1: compare the two run.json files and write the merged one."""
 81    ps, pd = os.path.join(src_run, "run.json"), os.path.join(dst_run, "run.json")
 82    if not os.path.exists(ps):
 83        raise FileNotFoundError(f"{ps} missing: expected <src>/output/<run_id>/run.json")
 84    new = json.load(open(ps))
 85    if not os.path.exists(pd):
 86        print("  run.json: none here yet, taking the other side's")
 87        _copy(ps, pd, dry)
 88        return
 89    with open(pd, "a+") as f:
 90        fcntl.flock(f, fcntl.LOCK_EX)
 91        f.seek(0)
 92        old = json.load(f)
 93        diffs = runstate.settings_diff(old, new)
 94        if diffs:
 95            lines = "\n".join(f"    {p}: here {a!r}, other side {b!r}" for p, a, b in diffs)
 96            if not force:
 97                raise ValueError(f"the two runs were made with different settings:\n{lines}\n"
 98                                 f"  -> they are different experiments; --force to combine anyway")
 99            print(f"  run.json: settings differ, combining anyway (--force):\n{lines}")
100        merged = {**runstate._merge(old, new),
101                  "created": min(old.get("created") or "~", new.get("created") or "~"),
102                  "updated": time.strftime("%Y-%m-%d %H:%M:%S")}
103        if not dry:
104            f.seek(0); f.truncate()
105            json.dump(merged, f, indent=2)
106        fcntl.flock(f, fcntl.LOCK_UN)
107    print("  run.json: " + ("merged" if diffs else "same settings"))

Step 2: the same cell trained twice?lines 110–119

Lists every model that exists on both sides with different weights. For those cells this side's model is kept, and nothing the other side computed from its own model (its ground-truth cache, its result rows) is copied.

110def _conflicts(src_root, dst_root):
111    """Step 2: {(process, variant, 'd<d>_K<K>_s<seed>')} trained on both sides differently."""
112    out = set()
113    for s in glob.glob(os.path.join(src_root, "checkpoints", "*", "*", "checkpoints", "model_*.pt")):
114        rel = os.path.relpath(s, src_root)
115        d = os.path.join(dst_root, rel)
116        if os.path.exists(d) and not _same_model(s, d):
117            proc, var = rel.split(os.sep)[1:3]
118            out.add((proc, var, os.path.basename(s)[len("model_"):-3]))
119    return out

combine(): step 3, the fileslines 122–180

Walks the other side's checkpoints/ and run folder and, file by file:

  • skips results files and figures (rebuilt later), run.json and history.log (merged separately) and anything belonging to a conflicting cell;
  • manifest.json: union of both, this side winning ties;
  • a file this side lacks: copied;
  • identical files, or a model with the same weights: nothing to do;
  • a cell file on both sides: rows this side lacks are added;
  • anything else that differs: this side's copy is kept, and reported.

Finally the two history logs are merged and a "combine" line is added. It returns counts of what happened.

122def combine(src_root, dst_root, run_id, force=False, dry=False):
123    src_root, dst_root = os.path.abspath(src_root), os.path.abspath(dst_root)
124    if src_root == dst_root:
125        raise ValueError("source and destination are the same folder")
126    src_run, dst_run = (os.path.join(r, "output", run_id) for r in (src_root, dst_root))
127    print(f"combine {src_root} (run {run_id})\n     -> {dst_root}" + ("   [dry run]" if dry else ""))
128    check_settings(src_run, dst_run, force, dry)
129    conflicts = _conflicts(src_root, dst_root)
130    for c in sorted(conflicts):
131        print(f"  CONFLICT {c[0]}/{c[1]} {c[2]}: trained on both machines with different weights "
132              f"-> keeping this side's model and everything derived from it")
133
134    def conflicted(parts):
135        name = os.path.splitext(parts[-1])[0].replace("model_", "")
136        if parts[0] == "checkpoints" and len(parts) >= 5:         # checkpoints/<proc>/<var>/...
137            return (parts[1], parts[2], name) in conflicts
138        if parts[-2] == "cells":                                  # output/<run>/<proc>/<var>/T/cells/
139            return (parts[2], parts[3], name) in conflicts
140        return False
141
142    stats = dict.fromkeys(("copied", "same", "cells_merged", "skipped_conflict", "kept_ours"), 0)
143    for tree in (os.path.join(src_root, "checkpoints"), src_run):
144        for root, _, files in os.walk(tree):
145            for fn in files:
146                s = os.path.join(root, fn)
147                rel = os.path.relpath(s, src_root)
148                d = os.path.join(dst_root, rel)
149                if fn in REBUILT or fn in ("run.json", "history.log") or fn.endswith((".png", ".tmp")):
150                    continue
151                if conflicted(rel.split(os.sep)):
152                    stats["skipped_conflict"] += 1
153                elif fn == "manifest.json":
154                    ours = json.load(open(d)) if os.path.exists(d) else {}
155                    _write_json(d, {**_relocate(json.load(open(s)), dst_root), **ours}, dry)
156                elif not os.path.exists(d):
157                    _copy(s, d, dry)
158                    stats["copied"] += 1
159                elif filecmp.cmp(s, d, shallow=False) or fn.startswith("model_"):
160                    stats["same"] += 1                  # a model on both sides with the same weights
161                elif rel.split(os.sep)[-2] == "cells":
162                    here = json.load(open(d))["rows"]
163                    have = {(int(r["n_per_mode"]), r["model"]) for r in here}
164                    extra = [r for r in json.load(open(s))["rows"]
165                             if (int(r["n_per_mode"]), r["model"]) not in have]
166                    _write_json(d, {"rows": here + extra}, dry)   # evaluate.merge re-sorts them
167                    stats["cells_merged" if extra else "same"] += 1
168                else:
169                    print(f"  kept this side's {rel} (the other side's copy differs)")
170                    stats["kept_ours"] += 1
171
172    hs, hd = os.path.join(src_run, "history.log"), os.path.join(dst_run, "history.log")
173    if os.path.exists(hs) and not dry:
174        lines = set(open(hd).read().splitlines()) if os.path.exists(hd) else set()
175        lines |= set(open(hs).read().splitlines())
176        with open(hd, "w") as f:
177            f.write("\n".join(sorted(l for l in lines if l.strip())) + "\n")
178            f.write(f"{time.strftime('%Y-%m-%d_%H-%M-%S')}  combine  from {src_root}\n")
179    print("  files: " + ", ".join(f"{k}={v}" for k, v in stats.items()))
180    return stats

rebuild(): step 4, results and figureslines 183–200

For every <process>/<variant>/T<T> folder with cell files, it builds a configuration with Hydra's compose (the same way main.py would), then runs evaluate.merge and visualize.run. A figure failing does not stop the rebuild.

183def rebuild(dst_root, run_id):
184    """Step 4: results.json / csv + figures of every <process>/<variant>/T<T>/ with cell files."""
185    from hydra import compose, initialize_config_dir
186    import evaluate
187    import visualize
188    conf = os.path.join(os.path.dirname(os.path.dirname(os.path.abspath(__file__))), "conf")
189    run = os.path.join(dst_root, "output", run_id)
190    for cells in sorted(glob.glob(os.path.join(run, "*", "*", "T*", "cells"))):
191        proc, var, T = os.path.relpath(os.path.dirname(cells), run).split(os.sep)
192        with initialize_config_dir(config_dir=conf, version_base=None):
193            cfg = compose("config", overrides=[
194                f"run_id={run_id}", f"paths.root={dst_root}", f"process={proc}",
195                f"data.weighted={'true' if var == 'weighted' else 'false'}", f"process.T_true={T[1:]}"])
196        evaluate.merge(cfg)
197        try:
198            visualize.run(cfg)
199        except Exception as e:                        # figures are a convenience; results are not
200            print(f"  [visualize {proc}/{var}/{T}] skipped: {e}")

main(): the command linelines 203–227

Options: --run (needed only if the source has several runs), --into (this repository's root; default $ATLAS_ROOT or the current folder), --force, --dry-run, --no-rebuild.

203def main():
204    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
205    ap.add_argument("src", help="folder holding the other machine's checkpoints/ and output/<run_id>/")
206    ap.add_argument("--run", help="run_id (default: the only run under <src>/output/)")
207    ap.add_argument("--into", help="this repository's root (default: $ATLAS_ROOT or the cwd)")
208    ap.add_argument("--force", action="store_true", help="combine even if the settings differ")
209    ap.add_argument("--dry-run", action="store_true", help="report only; change nothing")
210    ap.add_argument("--no-rebuild", action="store_true", help="do not rebuild results.json / figures")
211    a = ap.parse_args()
212    run_id = a.run
213    if run_id is None:
214        runs = [r for r in os.listdir(os.path.join(a.src, "output"))
215                if os.path.exists(os.path.join(a.src, "output", r, "run.json"))]
216        if len(runs) != 1:
217            ap.error(f"pass --run: runs under {a.src}/output: {runs}")
218        run_id = runs[0]
219    dst = os.path.abspath(a.into or os.environ.get("ATLAS_ROOT", os.getcwd()))
220    combine(a.src, dst, run_id, a.force, a.dry_run)
221    if not (a.dry_run or a.no_rebuild):
222        rebuild(dst, run_id)
223    print("done.")
