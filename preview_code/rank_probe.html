A separate side experimentlines 1–23

This file uses nothing else from the repository. It copies the few functions it needs, so it can be pasted into a notebook. The question: do the seeds that hallucinate fill seed space in every direction, or do they lie on a thin, low-dimensional set?

It collects about 100 000 hallucinating seeds with the exact DDIM sampler (no trained network), then measures how many dimensions they really use, compared with ordinary Gaussian noise of the same size. Edit the CONFIG block and run it. Only numpy and torch are needed; scipy is optional.

 1#!/usr/bin/env python
 2# ==========================================================================================
 3# rank_probe — SELF-CONTAINED: is the DDIM hallucination set low-rank?
 4#
 5# Depends on NOTHING in the repo. Needs numpy + torch (scipy optional). Runs three ways:
 6#     !python rank_probe.py          %run rank_probe.py          (or paste the whole file in a cell)
 7# Edit the CONFIG block below; everything else is self-contained.
 8#
 9# A seed is a point in NOISE space (x ~ N(0,I)); the DDIM map carries it to DATA space. A seed
10# "hallucinates" if its endpoint lands in no mode ball. We gather ~n_hall hallucinators and
11# measure how many dimensions their coordinates occupy in:
12#   (1) HALL @ noise : the seeds x0        (2) HALL @ data : their endpoints
13#   (3) GAUSS base   : fresh N(0,I) draws (the unstructured control)
14#
15# Naive matrix rank is trivially d for all three (n >> d, continuous data) -- reported so you
16# can see it saturate, but the signal is the SVD/effective-rank block on the mean-centred
17# (PCA) matrix: structured set -> effrank << d, n99 << d ; Gaussian noise -> ~= d.
18# ==========================================================================================

chi2_ppf(): R99 without scipylines 46–53

Uses scipy when available; otherwise the Wilson–Hilferty approximation, which turns the chi-square percentile into a normal one. Accurate enough for R99.

46def chi2_ppf(q, dof):
47    try:
48        from scipy.stats import chi2
49        return float(chi2.ppf(q, dof))
50    except Exception:                                   # Wilson-Hilferty, stdlib only
51        z = NormalDist().inv_cdf(q)
52        t = 1.0 - 2.0 / (9.0 * dof) + z * math.sqrt(2.0 / (9.0 * dof))
53        return float(dof * t ** 3)

 56def r99(d, sigma, q=0.99):
 57    return float(math.sqrt(chi2_ppf(q, d)) * sigma)

 60def make_schedule(T, bmin, bmax, dev):
 61    abar = np.cumprod(1.0 - np.linspace(bmin, bmax, T))
 62    return torch.tensor(abar, dtype=torch.float32, device=dev)

 65def sample_modes(K, d, R, sigma, m_mult, seed, dev):
 66    min_sep = m_mult * 2 * r99(d, sigma)
 67    rng = np.random.RandomState(seed)
 68    modes = np.empty((K, d))
 69    n, tries, mx = 0, 0, 10_000 * K
 70    while n < K and tries < mx:
 71        tries += 1
 72        v = rng.randn(d)
 73        v *= R / np.linalg.norm(v)
 74        if n and np.linalg.norm(modes[:n] - v, axis=1).min() < min_sep:
 75            continue
 76        modes[n] = v
 77        n += 1
 78    if n < K:
 79        raise RuntimeError(f"placed only {n}/{K} modes (min_sep={min_sep:.3f}); "
 80                           f"raise radius or lower sigma/K")
 81    return torch.tensor(modes.astype(np.float32), device=dev), float(min_sep)

 84@torch.no_grad()
 85def true_score(X, Mt, v):
 86    w = torch.softmax(-(torch.cdist(X, Mt) ** 2) / (2 * v), 1)
 87    return (w @ Mt - X) / v
 88
 89
 90@torch.no_grad()
 91def _eps(x, M, ab, var):
 92    v = ab * var + (1 - ab)
 93    return -torch.sqrt(1 - ab) * true_score(x, torch.sqrt(ab) * M, v)
 94
 95
 96@torch.no_grad()
 97def _step(x, eps, ab, abp):
 98    x0 = (x - torch.sqrt(1 - ab) * eps) / torch.sqrt(ab)
 99    return torch.sqrt(abp) * x0 + torch.sqrt(1 - abp) * eps

102@torch.no_grad()
103def forward_map(X0, M, abar, T, var, order="heun", chunk=100_000):
104    """Carry seeds X0 (noise) forward to data space under the exact GMM score."""
105    heun = str(order).lower() == "heun"
106    levels = [(abar[i], abar[i - 1]) for i in reversed(range(1, T))]
107    X = X0.clone()
108    for ab, abp in levels:
109        for s in range(0, X.shape[0], chunk):
110            xs = X[s:s + chunk]
111            e1 = _eps(xs, M, ab, var)
112            if heun:
113                e1 = 0.5 * (e1 + _eps(_step(xs, e1, ab, abp), M, abp, var))
114            X[s:s + chunk] = _step(xs, e1, ab, abp)
115    return X
116
117
118@torch.no_grad()
119def label_fate(Xf, M, R99, chunk=100_000):
120    lab = torch.empty(Xf.shape[0], dtype=torch.long, device=Xf.device)
121    for s in range(0, Xf.shape[0], chunk):
122        dmin, arg = torch.cdist(Xf[s:s + chunk], M).min(1)
123        lab[s:s + chunk] = torch.where(dmin <= R99, arg, torch.full_like(arg, -1))
124    return lab

rank_report(): how many dimensions does a point cloud use?lines 127–146

The singular values of the data matrix say how much the cloud spreads in each direction. Several summaries:

  • naive rank: directions with any spread at all. With many noisy points it is always d, so it cannot tell anything apart; reported only to show that.
  • effective rank: exp(entropy of the normalised singular values). About d for round noise; much smaller if a few directions dominate.
  • stable rank and participation ratio: two more ways of counting the dominant directions.
  • n90 / n95 / n99: how many principal directions hold 90 / 95 / 99% of the variance.

The data is centred first (subtract the mean), which makes this a PCA.

127def rank_report(A, name, dev):
128    A = A.to(device=dev, dtype=torch.float64)
129    n, dd = A.shape
130    s_raw = torch.linalg.svdvals(A)
131    tol = s_raw.max() * max(n, dd) * torch.finfo(s_raw.dtype).eps
132    naive = int((s_raw > tol).sum())
133    s = torch.linalg.svdvals(A - A.mean(0, keepdim=True))
134    s = s[s > 0]
135    s2 = s ** 2
136    p = s / s.sum()
137    effrank = float(torch.exp(-(p * torch.log(p)).sum()))
138    stable = float(s2.sum() / s2[0])
139    pr = float((s2.sum() ** 2) / (s2 ** 2).sum())
140    cum = torch.cumsum(s2, 0) / s2.sum()
141    n90 = int((cum < 0.90).sum()) + 1
142    n95 = int((cum < 0.95).sum()) + 1
143    n99 = int((cum < 0.99).sum()) + 1
144    return {"name": name, "n": n, "d": dd, "naive_rank": naive, "effrank": effrank,
145            "stable_rank": stable, "participation_ratio": pr, "n90": n90, "n95": n95,
146            "n99": n99, "svals": s.detach().cpu().numpy()}

mode_subspace_energy(): lined up with the modes?lines 149–157

The K mode centres span at most K−1 directions. This measures what share of the cloud's spread lies within those directions. Plain noise gives about (K−1)/d; a much higher value means the hallucinating seeds are organised around the arrangement of the modes.

149def mode_subspace_energy(A, M, dev):
150    A = A.to(device=dev, dtype=torch.float64)
151    M = M.to(device=dev, dtype=torch.float64)
152    Ac = A - A.mean(0, keepdim=True)
153    Q = torch.linalg.svd((M - M.mean(0, keepdim=True)).T, full_matrices=False).U
154    tot = (Ac ** 2).sum()
155    if tot <= 0:
156        return float("nan")
157    return float(((Ac @ Q) ** 2).sum() / tot)

Running the probelines 167–251

  1. Set up the world: R99, mode centres, schedule.
  2. Collect: draw seeds, run the exact sampler, keep the ones whose endpoint lands in no ball, and print progress.
  3. Build a Gaussian control set of the same size.
  4. Report ranks for three clouds: hallucinating seeds (noise space), their endpoints (data space), and the control; then the mode-subspace shares and the top singular values.
  5. Print a plain-language reading ("READ:") and optionally save everything to an .npz file.
