The predictorslines 1–18

Four ways to guess a seed's fate from its coordinates. All of them output K+1 scores per seed: column 0 for "hallucination", columns 1…K for the modes.

namekindidea
knnnon-parametriclook at the 10 nearest backtracked anchors and take a vote
altered_knnnon-parametricweighted vote among mode anchors only; an unsure vote means hallucination
quadratictraineda linear classifier on x and all products xixj: curved (quadratic) boundaries
polar3traineddescribes a seed by direction and radius; hallucination = close to the boundary between two modes
 1"""fate.py — predictors of a seed's fate, fit on backtracked anchors, and their scores.
 2
 3Classes: -1 = hallucination, 0..K-1 = the modes. Every predictor maps seeds (n, d) to
 4K+1 logits, column 0 the hallucination class.
 5
 6    knn          vote of the k nearest anchors (seed space)
 7    altered_knn  weighted kNN over MODE-only anchors (core.altered_knn_anchors); a seed whose
 8                 vote is low-confidence (normalised entropy) is a hallucination
 9    quadratic    linear classifier on (x, all pairwise products x_i x_j)
10    polar        degree-p polynomial in (direction, radius) giving K mode logits; the
11                 hallucination logit is c + a (r - sqrt d) - beta (top1 - top2 mode logit),
12                 i.e. "a hallucination lies within a radius-dependent margin of a mode boundary"
13"""

_chunk(): keep distance matrices smalllines 24–25

Comparing each query seed with millions of anchors needs a big distance matrix. This picks how many queries to handle at once so the matrix stays near 2·10⁸ numbers (~800 MB).

24def _chunk(n_stored):
25    return max(16, int(2e8 // max(n_stored, 1)))       # ~800 MB of distances per block

KNN: the nearest-neighbour votelines 28–49

fit just stores the anchors and their labels (one-hot, hallucination in column 0). forward finds each seed's k = 10 nearest anchors and returns the log of the share of votes for each class. The class with the most votes wins.

28class KNN(nn.Module):
29    """k-nearest-anchor vote; forward returns log class frequencies."""
30
31    def __init__(self, K, k=10):
32        super().__init__()
33        self.arch, self.K, self.k = "knn", K, int(k)
34        self.register_buffer("X", torch.zeros(0))
35        self.register_buffer("Y", torch.zeros(0))
36
37    @torch.no_grad()
38    def fit(self, X, y):
39        self.X, self.Y = X, nn.functional.one_hot(y + 1, self.K + 1).float()
40        return self
41
42    @torch.no_grad()
43    def forward(self, x):
44        out = []
45        for s in range(0, x.shape[0], _chunk(self.X.shape[0])):
46            D = torch.cdist(x[s:s + _chunk(self.X.shape[0])], self.X)
47            idx = D.topk(min(self.k, D.shape[1]), dim=1, largest=False).indices
48            out.append(torch.log(self.Y[idx].mean(1) + 1e-9))
49        return torch.cat(out)

AlteredKNN: hallucination = low confidencelines 52–113

Trained only on ring anchors, which are all labelled with a mode. For a seed:

  1. take the 10 nearest anchors; each votes for its mode with its ring weight;
  2. sharpen the vote shares with a softmax at temperature 0.1;
  3. confidence = 1 − entropy / log K (1 = all neighbours agree, 0 = evenly split), or simply the largest share;
  4. confidence below the threshold → hallucination.

calibrate picks the threshold automatically: it tries 100 cut-offs (the 0.5% to 50% quantiles of the confidences on the calibration seeds) and keeps the one with the best hallucination F1 against the exact field's labels. forward turns the decision into a hard ±30 score in column 0 so that it always wins or always loses.

 52class AlteredKNN(nn.Module):
 53    """Weighted kNN over mode-labelled anchors; hallucination = low confidence.
 54
 55    The k nearest anchors vote s_k = sum_i w_i [y_i = k] / sum_i w_i, p = softmax(s / temperature)
 56    (p = s for temperature <= 0). Confidence is 1 - H(p) / log K ('entropy') or max p ('max');
 57    a seed is a hallucination iff confidence < threshold ('auto': fit by calibrate())."""
 58
 59    def __init__(self, K, k=10, temperature=0.1, threshold=0.5, confidence="entropy"):
 60        super().__init__()
 61        self.arch, self.K, self.k = "altered_knn", K, int(k)
 62        self.temperature, self.confidence = float(temperature), confidence
 63        self.threshold = None if threshold == "auto" else float(threshold)
 64        self.register_buffer("X", torch.zeros(0))
 65        self.register_buffer("Y", torch.zeros(0))
 66        self.register_buffer("W", torch.zeros(0))
 67
 68    @torch.no_grad()
 69    def fit(self, X, y, w=None):
 70        keep = y >= 0                                  # mode anchors only
 71        X, y = X[keep], y[keep]
 72        self.W = torch.ones(X.shape[0], device=X.device) if w is None else w[keep].float()
 73        self.X, self.Y = X, nn.functional.one_hot(y, self.K).float()
 74        return self
 75
 76    @torch.no_grad()
 77    def conf(self, x):
 78        """(class probabilities, confidence) of seeds x."""
 79        out = []
 80        for s in range(0, x.shape[0], _chunk(self.X.shape[0])):
 81            D = torch.cdist(x[s:s + _chunk(self.X.shape[0])], self.X)
 82            idx = D.topk(min(self.k, D.shape[1]), dim=1, largest=False).indices
 83            wv = self.W[idx]
 84            votes = (wv[:, :, None] * self.Y[idx]).sum(1) / wv.sum(1, keepdim=True).clamp_min(1e-12)
 85            out.append(torch.softmax(votes / self.temperature, 1) if self.temperature > 0 else votes)
 86        p = torch.cat(out)
 87        if self.confidence == "max":
 88            return p, p.max(1).values
 89        H = -(p * torch.log(p.clamp_min(1e-12))).sum(1)
 90        return p, 1 - H / math.log(max(self.K, 2))
 91
 92    @torch.no_grad()
 93    def calibrate(self, X_cal, y_cal):
 94        """threshold := the confidence cut maximising hallucination F1 on labelled seeds."""
 95        _, c = self.conf(X_cal)
 96        hall = y_cal == -1
 97        best, best_f1 = 0.0, -1.0
 98        for th in torch.quantile(c, torch.linspace(0.005, 0.5, 100, device=c.device)).tolist():
 99            pred = c < th
100            tp, fp, fn = int((pred & hall).sum()), int((pred & ~hall).sum()), int((~pred & hall).sum())
101            f1 = 2 * tp / max(2 * tp + fp + fn, 1)
102            if f1 > best_f1:
103                best, best_f1 = th, f1
104        self.threshold = best
105        return self
106
107    @torch.no_grad()
108    def forward(self, x):
109        if self.threshold is None:
110            raise RuntimeError("altered_knn with threshold=auto needs calibrate() first")
111        p, conf = self.conf(x)
112        zh = torch.where(conf < self.threshold, torch.full_like(conf, 30.0), torch.full_like(conf, -30.0))
113        return torch.cat([zh[:, None], torch.log(p.clamp_min(1e-12))], 1)

FateNet: the two trained predictorslines 116–144

quadratic: the input is x plus every product xi·xj (i ≤ j), fed to one linear layer. That can draw any quadratic boundary (ellipsoids, hyperboloids). There are d(d+1)/2 products: 528 at d = 32, 131 328 at d = 512.

polar: a seed x ~ N(0, I) has length close to √d, so it is described by its direction x/|x| and how far its length is from √d. A projection to 256 features and their powers 1…3 (a degree-3 polynomial) give the K mode scores. The hallucination score is

c + a · (|x| − √d) − β · (best mode score − second-best mode score)

In words: a seed is likely to hallucinate when the model can hardly decide between its two best modes, i.e. near a boundary between their regions. The radius term lets that depend on how far out the seed is. c, a and β are learned.

116class FateNet(nn.Module):
117    """The parametric predictors (quadratic, polar); see the module docstring."""
118
119    def __init__(self, d, K, arch="polar", hidden=256, degree=3):
120        super().__init__()
121        if arch not in PARAMETRIC:
122            raise ValueError(f"unknown parametric arch {arch!r}; choose from {PARAMETRIC}")
123        self.arch, self.d, self.K, self.degree = arch, d, K, degree
124        if arch == "quadratic":
125            self.register_buffer("iu", torch.triu_indices(d, d))
126            self.net = nn.Linear(d + self.iu.shape[1], K + 1)
127        else:
128            self.proj = nn.Linear(d + 1, hidden)
129            self.net = nn.Linear(hidden * degree, K)
130            self.c = nn.Parameter(torch.zeros(()))
131            self.a = nn.Parameter(torch.zeros(()))
132            self.log_beta = nn.Parameter(torch.zeros(()))
133
134    def forward(self, x):
135        if self.arch == "quadratic":
136            return self.net(torch.cat([x, x[:, self.iu[0]] * x[:, self.iu[1]]], 1))
137        mu = math.sqrt(self.d)                                     # typical seed radius
138        r = x.norm(dim=1, keepdim=True)
139        rs = r - mu
140        z = self.proj(torch.cat([x / r * math.sqrt(mu), rs], 1)) / math.sqrt(mu + 1)
141        zm = self.net(torch.cat([z ** q for q in range(1, self.degree + 1)], 1))   # mode logits
142        top = zm.topk(2, dim=1).values
143        zh = self.c + self.a * rs[:, 0] - self.log_beta.exp() * (top[:, 0] - top[:, 1])
144        return torch.cat([zh[:, None], zm], 1)

train_fate_classifier(): fit one predictorlines 147–172

kNN-type predictors are "fitted" by storing the anchors. The trained ones use AdamW with a one-cycle learning rate (warm up, then decay), cross-entropy loss, at least 30 epochs and at least min_steps = 3000 gradient steps. Labels are shifted by one so that −1 → class 0.

147def train_fate_classifier(X, y, K, arch, hidden=256, degree=3, epochs=30, batch=2048, lr=3e-3,
148                          weight_decay=1e-4, min_steps=0, k=10, temperature=0.1, threshold=0.5,
149                          confidence="entropy", w=None, seed=0, device=None):
150    """Fit one predictor on seeds X (n, d) with fates y. Non-parametric ones store the anchors;
151    parametric ones run AdamW + one-cycle lr for `epochs` passes, at least `min_steps` steps."""
152    if arch == "altered_knn":
153        return AlteredKNN(K, k, temperature, threshold, confidence).to(device).fit(X, y, w)
154    if arch == "knn":
155        return KNN(K, k).to(device).fit(X, y)
156    torch.manual_seed(seed)
157    net = FateNet(X.shape[1], K, arch, hidden, degree).to(device)
158    opt = torch.optim.AdamW(net.parameters(), lr=lr, weight_decay=weight_decay)
159    n = X.shape[0]
160    batch = min(batch, n)
161    per_epoch = max(1, n // batch)
162    epochs = max(epochs, -(-min_steps // per_epoch))
163    sched = torch.optim.lr_scheduler.OneCycleLR(opt, max_lr=lr, total_steps=epochs * per_epoch)
164    yl = y + 1                                                    # class index: 0 = hallucination
165    for _ in range(epochs):
166        perm = torch.randperm(n, device=device)
167        for s in range(0, n - batch + 1, batch):
168            i = perm[s:s + batch]
169            loss = nn.functional.cross_entropy(net(X[i]), yl[i])
170            opt.zero_grad(); loss.backward(); opt.step(); sched.step()
171    net.eval()
172    return net

train_ensemble(): three models are steadier than onelines 175–185

Trains ensemble = 3 copies of a trained predictor with seeds 0, 1, 2 (just one for kNN-type predictors, which have no randomness). Their predictions are combined below.

175def train_ensemble(X, y, K, spec: dict, device=None, w=None):
176    """spec['ensemble'] predictors from one conf/classifier spec (one if non-parametric);
177    w = anchor weights (altered_knn only)."""
178    kw = dict(arch=spec["arch"], hidden=spec["hidden"], degree=spec["degree"],
179              epochs=spec["epochs"], batch=spec["batch"], lr=spec["lr"],
180              weight_decay=spec["weight_decay"], min_steps=spec["min_steps"], k=spec["k"],
181              temperature=spec["temperature"], threshold=spec["threshold"],
182              confidence=spec["confidence"], w=w if spec["arch"] == "altered_knn" else None,
183              device=device)
184    n_ens = 1 if spec["arch"] in NONPARAMETRIC else spec["ensemble"]
185    return [train_fate_classifier(X, y, K, seed=e, **kw) for e in range(n_ens)]

predict_fate(): scores → a fatelines 188–199

Adds the ensemble's log-probabilities. The seed is called a hallucination if the hallucination score beats the best mode score, otherwise it gets the best mode. For quadratic the chunk is shrunk so the d(d+1)/2 product features stay under ~2 GB.

188@torch.no_grad()
189def predict_fate(nets, X, chunk=100000):
190    """Ensemble prediction (summed log-probabilities) -> fates in {-1, 0..K-1}."""
191    quad = [int(n.iu.shape[1]) for n in nets if n.arch == "quadratic"]
192    if quad:                     # d(d+1)/2 pairwise features: keep a block's features under ~2 GB
193        chunk = max(1024, min(chunk, int(2e9 // (4 * max(quad)))))
194    out = []
195    for s in range(0, X.shape[0], chunk):
196        lp = sum(torch.log_softmax(net(X[s:s + chunk]), 1) for net in nets)
197        best, k = lp[:, 1:].max(1)
198        out.append(torch.where(lp[:, 0] - best > 0, torch.full_like(k, -1), k))
199    return torch.cat(out)

fate_metrics(): how the atlas is gradedlines 202–225

scorequestion it answers
full_accshare of all seeds whose fate was guessed exactly
mode_accamong seeds that truly go to a mode: share given the right mode
mode_f1F1 per mode, averaged over modes (so small modes count equally)
hall_precof the seeds called hallucinations, the share that really are
hall_recof the seeds that really hallucinate, the share that were caught
hall_f1the balance of the two: 2·P·R / (P + R)
balancedaverage of mode_acc and hall_f1

Example. 1000 seeds, 20 of which really hallucinate. A predictor flags 30 seeds, 15 of them correctly. Precision = 15/30 = 0.50, recall = 15/20 = 0.75, F1 = 0.60.

When real hallucinations are very rare (say 0.2% of seeds), even a good detector gets a low precision, because its false alarms outnumber the few true cases. Read hall_f1 together with hall_gt, the true hallucination rate stored in each row.

202# --------------------------------------------------------------------------------------
203# scores of predicted vs ground-truth fates
204# --------------------------------------------------------------------------------------
205METRICS = ("full_acc", "mode_acc", "mode_f1", "hall_prec", "hall_rec", "hall_f1", "balanced")
206
207
208def _f1(pred_pos, gt_pos):
209    tp = int((pred_pos & gt_pos).sum()); fp = int((pred_pos & ~gt_pos).sum())
210    fn = int((~pred_pos & gt_pos).sum())
211    prec, rec = tp / max(tp + fp, 1), tp / max(tp + fn, 1)
212    return prec, rec, 2 * prec * rec / max(prec + rec, 1e-9)
213
214
215def fate_metrics(pred, gt) -> dict:
216    """full_acc: all seeds; mode_acc / mode_f1 (macro): seeds whose true fate is a mode;
217    hall_*: the hallucination class; balanced: mean of mode_acc and hall_f1."""
218    m_mode = gt >= 0
219    mode = float((pred[m_mode] == gt[m_mode]).float().mean()) if m_mode.any() else float("nan")
220    prec, rec, f1 = _f1(pred == -1, gt == -1)
221    modes = torch.unique(gt[m_mode]).tolist()
222    mode_f1 = float(sum(_f1(pred == k, gt == k)[2] for k in modes) / max(len(modes), 1))
223    return {"full_acc": float((pred == gt).float().mean()), "mode_acc": mode, "mode_f1": mode_f1,
224            "hall_prec": prec, "hall_rec": rec, "hall_f1": f1,
225            "balanced": 0.5 * (mode + f1) if mode == mode else float("nan")}
